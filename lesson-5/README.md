# Terraform Infrastructure — Lesson 5

Цей проєкт створює базову інфраструктуру AWS за допомогою Terraform. У складі використані три модулі:
- бекенд для зберігання Terraform state,
- мережевий модуль VPC,
- модуль для створення ECR-репозиторію.

## Опис модулів

### 1. s3-backend

Модуль відповідає за зберігання Terraform state.

Створює:
- S3 bucket для стейт-файлів Terraform;
- DynamoDB-таблицю для блокування state;
- версіювання bucket для збереження історії змін.

У вихідних даних модуля:
- назва S3 bucket;
- ім’я DynamoDB-таблиці.

---

### 2. vpc

Модуль створює базову мережеву інфраструктуру.

Створює:
- VPC із заданим CIDR-блоком;
- 3 публічні підмережі;
- 3 приватні підмережі;
- Internet Gateway для публічних підмереж;
- NAT Gateway для приватних підмереж;
- таблиці маршрутизації для публічної та приватної частини.

У вихідних даних модуля:
- ID VPC;
- списки ID публічних та приватних підмереж.

---

### 3. ecr

Модуль створює репозиторій для Docker-образів у AWS ECR.

Створює:
- ECR-репозиторій;
- автоматичне сканування образів при завантаженні (scan on push).

У вихідних даних модуля:
- URL створеного ECR-репозиторію.

---

## Команди для роботи з інфраструктурою

### Ініціалізація Terraform

terraform init

### Перевірка плану змін

terraform plan

### Створення інфраструктури

terraform apply

### Видалення всіх ресурсів

terraform destroy

---

## Додаткова інформація

Після повного видалення інфраструктури за допомогою `terraform destroy` буде видалено також S3 bucket та DynamoDB-таблицю, які використовуються для зберігання Terraform state.

У такому випадку перед повторним запуском проєкту потрібно виконати повторну ініціалізацію з переналаштуванням бекенду:

terraform init -reconfigure
